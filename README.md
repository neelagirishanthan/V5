# V5 Event Management

Customer-facing documents for V5 Event Management's Indian wedding planning.

| Folder | What it is |
|---|---|
| `intake-form/` | Online customer intake form (events, guest counts, decor, food, bar, DJ, priest, photography, accommodation) |
| `intake-flyer/` | Printable 3-page A4 intake flyer, HTML source and PDF |
| `quotes/feb-2027-wedding/` | Price quote for the February 2027 wedding, HTML source and PDF |
| `agreements/feb-2027-wedding/` | Wedding services agreement for the February 2027 wedding, HTML source and PDF |

Each PDF is rendered from the HTML file next to it with headless Chromium (Playwright) at A4 size.
Placeholders in square brackets, such as `[COUPLE NAMES]`, still need filling in before the documents go to a client.

## Website

The public website lives in `site/` and is deployed by Netlify (`netlify.toml` publishes only that folder):

- `site/index.html`: home page (photo placeholders until real photos arrive)
- `site/calendar/`: public calendar of celebrations, with "check your date"
- `site/data/calendar.json`: the calendar's entries; edit this file to add or update celebrations
- `site/intake/`: customer intake form; submissions go to Netlify Forms (form name `intake`).
  It accepts `?events=haldi,pelli&guests=250&date=2027-02-14` to prefill from the home page planner or the calendar.
- `site/thanks/`: page shown after a customer submits
- `site/assets/`: shared CSS and JS, and the logo (`logo.svg`, `logo-light.svg`, `mark.svg`)

The logo is generated by `tools/make_logo.py` from the Rozha One and Martel Sans fonts (Google Fonts),
with the text converted to outlines so it looks the same everywhere.

## Thank-you email after an intake submission

`netlify/functions/submission-created/` runs on Netlify each time an intake form is submitted.
It emails the customer from v5eventhub@gmail.com with two PDFs attached: their intake summary
(built from the submission) and the service terms (`site/assets/V5-Events-Service-Terms.pdf`),
and sends a copy to the same Gmail account.

It needs two environment variables in Netlify (Project configuration → Environment variables):

- `GMAIL_USER` = `v5eventhub@gmail.com`
- `GMAIL_APP_PASSWORD` = a Google app password for that account (Google Account → Security →
  2-Step Verification → App passwords). Mark it as a secret.

Without them the function does nothing and submissions are still saved in Netlify Forms.
`npm run test:email` builds the email and PDFs from a sample submission without sending anything.
